Privacy Policy — F12 Plus Analytics

Last updated: September 2026

F12 Plus Analytics ("this app") is an internal analytics tool built and used solely by the operator of the False 12 Plus YouTube channel to pull performance data for that channel's own videos.

What this app accesses

Using Google's OAuth 2.0 authorization, this app requests read-only access to:

  • Basic YouTube channel and video metadata (via the YouTube Data API)
  • YouTube Analytics performance data for the authorized channel's own videos — views, watch time, engagement, and traffic-source metrics (via the YouTube Analytics API)

This app does not request write access to any Google account, does not post, upload, delete, or modify any content, and does not access data for any channel other than the one explicitly authorized by its owner.

How the data is used

Data retrieved through these APIs is used only to populate a private, internal performance dashboard for the channel owner's own reference. It is not sold, shared with third parties, or used for advertising.

Where the data is stored

Retrieved data is stored locally on the app owner's own devices and infrastructure. It is not transmitted to any third-party service other than Google's own APIs used to retrieve it.

Data retention and deletion

The app owner may delete locally stored data at any time. Access can be revoked at any time via Google Account permissions, which immediately stops this app from retrieving further data.
